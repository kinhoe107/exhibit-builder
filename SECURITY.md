# Security reports

The latest published Exhibit Builder release is the supported version.

Please report a suspected security vulnerability through GitHub's private
vulnerability-reporting feature on the repository's **Security** tab. Do not
place exploit details, confidential documents, personal data or client material
in a public issue.

Include the affected Exhibit Builder version, Windows version, a concise account
of the behaviour, reproduction steps using synthetic files where possible, and
the likely impact. Reports may be investigated, but no response time, support
service or correction is guaranteed.

Ordinary defects and usability problems can be reported through GitHub Issues,
provided the report contains no confidential or personal material.
