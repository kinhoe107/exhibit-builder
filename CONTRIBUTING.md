# Feedback and contributions

Exhibit Builder is publicly viewable proprietary software, not an open-source
project.

Bug reports and focused usability feedback are welcome through GitHub Issues.
Use synthetic documents, remove confidential information, identify the version
tested and describe the exact steps that produced the problem.

Pull requests and unsolicited code contributions are not accepted unless the
repository owner has invited them and agreed the applicable terms in writing.
Opening an issue does not grant a licence to the source code or create an
obligation to implement, support or respond to a proposal.
